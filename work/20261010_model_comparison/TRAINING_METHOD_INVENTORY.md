## Adaptations applied to this comparison

- Data becomes the common 89,267 × 1,024 ordered linear normalized spliced matrix. Old datasets, `log1p`/scaling, GRN species/IDs, and private absolute paths are not inherited.
- All pilot targets are START_X. B and D differ from historical EPSILON training. The ODE raw output may have been fit as a reconstruction predictor or a consistency branch; calling it ds/dt remains an experimental assumption.
- B/C/D use 30,000 fresh updates; E uses the final A01 EMA plus 10,000 ODE-only updates. These compare both initialization and compute, not only freezing. `X_stage1_hill_additive_freeze_true/false` starts from the same final EMA with matched stop/anneal settings.
- Legacy 8/30 anneals by completed updates; the comparison records and consistently uses the 9/16/10/09 post-update **zero-based** convention. E update 10,000 uses the LR after index 9998; the saved next LR is `1e-4*(1−9999/30000)`. A stop override never silently changes the LR horizon.
- Original Gaussian diffusion supplies float64 training noise and native ancestral `p_sample` with `nw=.5`, clipping disabled. No noise factor, field clamp or ODE integration is added by the adapter.
- Dedicated original `Batches` sampler gives identical shuffled row streams and exact CPU resume. Non-baseline runs reset diffusion RNG after construction to align timestep/noise streams across structures. Reused A01 retains its historical stream; bitwise identity with newly adapted runs is not claimed. Sampling uses the same seed and batch sizes, including initial Gaussian noise.
- Sparse graph fields have no off-support weights; their zero soft penalty is reported honestly. Nonempty graph mapping is still required.
- User-requested low-impact observational logging is added around baseline source train via hooks; loss/update code is unchanged. Reusing an old checkpoint cannot recover historical gradient diagnostics that were never logged.

## Registry statuses for training families

`registry.json` and `SOURCE_REUSE_MAP.md` distinguish implemented, requires-adapter and incompatible cases. None of PCA OT, trajectory OT, kNN, custom-forward ELBO, or dual-optimizer SGD is silently substituted with MSE. Missing real data, mapped edge counts and actual GPU success are not marked verified.
