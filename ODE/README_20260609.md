## 1. `ode_20260609_mathmlp.py` — 数理構造 + MLP の field 4 系統

各 field は時刻依存の線型作用素 `W(x,t)` を MLP でパラメタ化し、

```
V(x,t) = softplus(W(x,t) x + b) − softplus(γ) ⊙ x      （γ は GeneODE 風の符号付き減衰、--use_decay）
```

を返す。**forward では batched W (B×d×d) を materialize しない**（einsum の結合則を使う）。

| field | W(x,t) の構成 | 静的パラメタ | W_IS_EXACT |
|---|---|---|---|
| `LowRankField` | `U(x,t) V(x,t)^T`（U,V を MLP 生成） | `b`, `gamma`（静的 W 無し） | True（動的） |
| `LinCombField` | `V = Σ_k a_k(x,t) softplus(W_k x + b_k)` | `expert_W`(K,d,d), `expert_b`(K,d) | **False**（proxy: `Σ_k a_k W_k`） |
| `MatSumField` | `W = Σ_k a_k(x,t) A_k` | `A`(K,d,d), `b` | True |
| `LoRAField` | `W = W_0 + Σ_k a_k(x,t) U_k V_k^T` | `W0`(d,d), `U`/`V`(K,d,r), `b` | True |

- 共通: `time_emb`（sinusoidal `timestep_embedding`→MLP）、`gamma`(d,)（K 非依存）、`mask` buffer(d,d)。
  `forward(x, t=None)`（t 省略/NaN は t=0 扱い、GeneODE 互換）、`compute_W(x,t)→(B,d,d)`（可視化用・少数サンプル）、
  `off_mask_penalty(norm)`、`get_model_info()`。
- 正則化（off-mask 罰則）: lincomb/matsum/lora は静的パラメタ（x,t 非依存・安価）。lowrank は forward 内で
  batch を subsample して W を限定構築（`_cached_W_sub`、≤数十MB、`enable_offmask_cache` で gating）。
- `MathML_Hybrid`: field と `Cell_Unet` を `r(t)=1−t/(T−1)` で内分 blend する wrapper（`self.ode_model=field`）。
- `build_math_field(model_type, gene_list, edge_tsv_path, ...)`: tsv→mask を作って field を構築する factory。
- `load_hybrid_state_dict`: EMA/`module.`/ネストを剥がし（`clean_state_dict`）、missing/unexpected/shape-mismatch を
  ログ。`ode_model.*`/`ml_model.*` の不整合は **strict=True で RuntimeError**（誤 checkpoint 検出）。

> **lincomb の W は proxy**（`W_IS_EXACT=False`）。`compute_W` は preactivation 係数の線型近似 `Σ_k a_k W_k` で、
> 厳密な単一 `W(x,t)` ではない。可視化はタイトルに `[PROXY]` を付け、横比較の解釈に注意。

## 2. `ode_20260609_hybridnorm.py` — 出力統合 3 モード（GeneODE 専用）

`ODE_ML_HybridNorm` は `GeneODE` と `Cell_Unet` の出力統合方法を 3 つから選ぶ（排他）:

| mode | 出力 | training の `_cached_ratio_reg` | off_mask_penalty |
|---|---|---|---|
| `ratio_reg` | `r·ode + (1−r)·ml` | ratio penalty を cache | base + ratio_reg_weight·ratio |
| `normed_learned_scale` | `exp(log_scale)·(r·ode_unit + (1−r)·ml_unit)` | None | base のみ |
| `none` | `r·ode + (1−r)·ml` | None | base のみ |

- 最小差分の鍵: 既存 `GeneODE.off_mask_penalty()` は `_cached_ratio_reg is None` なら base のみ返す。
  本クラスが forward で mode 別に cache を出し分けるだけで、train_util も GeneODE も無編集で 3 mode 成立。
- `normed_learned_scale` のときだけ **共有 scalar `log_scale`** を 1 個生成（`scale=exp(log_scale)`、init=1.0）。
  ratio_reg/none は param 集合が現行と同一 → 既存 checkpoint 互換。
- eval 時は全 mode で `_cached_ratio_reg=None`（stale 防止）。不正 mode は `ValueError`。

## 3. `ode_20260609_hybrid5x3.py` — 5 枝 × 3 mode 統合 factory

`UnifiedODEMLHybrid` は ODE 枝（GeneODE or 4 math field）と `Cell_Unet` を上記 3 mode で統合する。
`ODE_ML_HybridNorm` との差は **forward が `ode_model(x, t)` と t を渡す**点のみ:

```
ode_out = self.ode_model(x, t)   # GeneODE は t 無視 / 4 field は t 使用 → 全 5 枝で時刻依存が保たれる
ml_out  = self.ml_model(x, t, y)
```

これで「field を hybrid に差すと t=0 で時刻依存が消える」問題（GeneODE 専用だった HybridNorm の制約）を解消。

- `build_ode_branch(branch, ...)`: branch ∈ {geneode, lowrank, lincomb, matsum, lora} を構築
  （geneode→`GeneODE`、4 field→`build_math_field`）。
- `build_denoiser(ode_branch, gene_list, edge_tsv_path, timesteps, hybrid_norm_mode, *, rank, K, soft,
  ode_reg_lambda, time_dim, field_hidden, field_dropout, use_decay, ratio_reg_weight, ratio_reg_target,
  hybrid_scale_init, hybrid_scale_eps, device)`: **全実験の統一エントリ**。
  - `ode_branch in 5枝` → `UnifiedODEMLHybrid`（`self.ode_model=branch` で hook 発火）。
  - `ode_branch == "plain"` → `Cell_Unet` 単体（ode_model 無し → hook 不発火、baseline）。
- train_util の `model.ode_model.off_mask_penalty(norm)` hook が全 hybrid 枝で無編集発火。`soft`/`ode_reg_lambda`
  で off-mask 構造罰則（`tf_target_edges.tsv` 由来の (d,d) edge mask）を制御。

復元（可視化/サンプリング）は `work/20260609_Hybrid5x3/viz/_restore.build_model` が `build_denoiser` 経由で
config json（`exp_config`/`field_config`/`hybrid_config`）から同型再構築する。
