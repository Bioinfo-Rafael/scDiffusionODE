# docs/
このディレクトリには、環境構築、既存ドキュメント、参照ファイル、移行記録など、コード本体以外の説明・記録系ファイルを集約しています。

## 配下の構成

```text
environment/       環境構築ファイル・セットアップスクリプト
documentation/     既存の説明資料
file_changes/      ファイル変更に関する記録
reference_files/   参照用ファイル
migration/         GitHub移行前後の記録・スナップショット
```

## 方針
GitHub移行前の整理では、root直下に散らばっていた説明・環境・移行記録系ディレクトリを `docs/` にまとめました。
